## ⚡ 结论（三句）

1. **用户的三个判断都成立，强弱不同。** personal agent 的证据最强：2026-09 到 10 月，OpenAI、Meta、腾讯、阿里、蚂蚁接连发布替人办事的个人助理（第 3 节）；其中 OpenAI 的 dots 明确是常驻在线的，几家国内产品的报道口径是「App 不在前台也能继续处理任务」。模型架构与推理系统在 Agent 岗面经里也会被问到一层（第 4、5 节），10 月把它整体定为「选修」，定低了。
2. **「Agent 的重点变了」要拆开说。** 骨架仍在考：上下文窗口、Agent Loop、死循环、MCP 与 Skill、RAG，2026-10 到 11 月都有原帖原样在问。变的是深度：Harness 从「是什么」问到「你来写一个」「两个 harness 差在哪」。另外冒出三个题库没有的点：跑到一半插话、computer use、你自己怎么用 AI 写代码。
3. **处置**：题单从一条线扩成四条：Agent 工程（T）、Personal Agent（P）、模型架构与算法（M）、AI Infra（I），新增 33 题（同日 v1.1 按设计法又给 P 线补了 5 题，共 46 题）。M 线的后训练部分从 Q13 进，I 线从 Q14 进。Q14–Q22 没有过时，其中 Q15、Q21、Q22 在 2026-10 的原帖里都被问到。

### 3.2 和已有题的结构差异

只列方向，题眼见题单。五处：

1. **谁叫醒它**：从「人发一句话」变成时钟、来信、事件。
2. **它拿着谁的钥匙**：替一个具体的人登录邮箱、日历、支付账户。
3. **它记住的是什么**：从「一个任务」变成「一个人」，而且要记很多个月。
4. **它跑在哪**：用户自己的电脑，还是云端专属虚拟机。
5. **对面让不让**：平台同不同意被代操作（Amazon 与 Muse；SAEP 与 155 个 App）。

第 5 处在 Q01–Q22 与 T01–T08 里**完全没有落点**。其余四处各有一道相邻题（Q09、Q20、Q15、Q11 / T04），但那些题都从「一个任务」出发，换成「一个人」之后要重新答。

### 3.3 面经现状

本轮没读到直接问 personal agent 的面经原帖。检索只见转述：一家小公司的面试反复问 OpenClaw 为什么走红、商业逻辑是什么（⚠️ 只见搜索摘要）。**下一轮面经的第一优先级就是找这条线的原帖**——找到后不是拿来出题，是拿来校准：映射到 P 线的设计题上，映射不上的说明需求或约束列漏了（v1.1 的方法）。

- DeepSeek-V4 预览版（2026-04-24）：总参 1.6T、激活 49B 的 MoE；注意力改成压缩加稀疏的混合设计，官方口径是 1M 上下文下 KV cache 只有 V3.2 的 10%（N19 ⚠️）。
- Kimi K3 用了线性注意力（KDA）的混合架构，vLLM 2026-07-22 为它写了生产级支持的预览（N20 ⚠️）。
- 反方向的事实：MiniMax M2 试过线性与稀疏注意力之后退回全注意力，2025-10-30 发了官方说明（N22 ⚠️）。

「每一层都做全注意力」已经不是默认，这件事本身成了可以问的设计取舍。

### 4.3 范围与入口

- RL 训练系统成了独立话题：生成和训练拆开、异步，rollout 做成独立服务（N21 ⚠️）。
