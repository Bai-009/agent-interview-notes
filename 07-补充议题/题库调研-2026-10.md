## ⚡ 结论（三句）

1. **22 题的骨架没过时。** 本轮样本（第 1 节）里反复出现的问法，多半能在 Q01–Q22 找到落点；Q03、Q07、Q08、Q09、Q11 几乎原样在考。落不下的就是第 3 句那几块。
2. **考法在三处变了**：「Harness」直接成题；问法从「是什么」转向「出了故障怎么办」（死循环、重试安全、多个 Agent 并发写同一份数据、断点续跑）；评测与线上追踪从加分项变成常问项。
3. **题库真正缺的是模型之外那一层**：Harness 的定义与解剖、Agent 的运行时与沙箱、Agent 与 Workflow 的取舍、agent 之间的协议（A2A）、可观测性。模型侧的推理服务（AI Infra）是另一条岗位线，按岗位选修。

## 5. AI Infra：两条线，不要混

用户 2026-10-12 补问「还有很多 AI infra 的部分对吧」。对，而且「AI Infra」在 2026 年招聘里是两样东西：

| | 模型侧（推理服务） | Agent 侧（运行时） |
| --- | --- | --- |
| 管什么 | 推理怎么跑得快、跑得省：批处理、KV cache、推理框架、GPU 调度 | Agent 跑在哪、怎么隔离、怎么断点续跑、怎么追踪：沙箱、会话、持久化、可观测 |
| 面经证据 | B、D·字节、I·Anthropic 各一题，牛客另有成组的 AI Infra 面经 ⚠️ 未读原帖——**原文与考点清单都放在第 4 节 Q14 折叠块**（与 Q14 推理降本重叠） | E「对 E2B 了解多少？」「是否使用过 E2B SDK 或类似的 Sandbox 方案？」 |
| 招聘证据 | — | J（Runtime、Serverless、持久化、可观测） |
| 本仓现状 | [[Q03-Token与上下文窗口与上下文腐化\|Q03]] 的 KV cache 与经济窗口；Q14 题目沾边 | [[Q11-MCP与Skill\|Q11]] 的「进程隔离 ≠ 沙箱」 |

## 6. 面试形式的变化

- **项目深挖占大头**：C、D 的题单里「实习拷打」「项目拷打」「这个项目的背景是什么？你们团队在做什么？」反复出现，概念题多数从项目追出来。→ 复习第三轮「模拟追问」要加一种练法：从自己的项目出发被追问。
- **后端基础照考**：MySQL 事务隔离级别、索引（E）；Redis 分布式锁、线程池、IO 多路复用（C、D）；手写算法（LRU、两个栈实现队列、岛屿最大面积）。Agent 岗不等于不考基础。
- ⚠️ **允许用 AI 工具的现场编程题**：只见个人叙述与平台文档转述，未读到大厂原帖；方向是「考你怎么指挥、审查、验证 AI 写的代码」。列为观察项，下轮面经重点找原帖。
- ⚠️ **「读过 Claude Code 源码吗」**：多条阿里系转述，未读到原帖。答题以公开文档和本机可观察的行为为据（台账「本机行为核对」观察项），不复述来源不明的代码细节。
