## 二期：前沿题库（Q22 完成后由维护方产出）

> 用户 2026-08-28 定调：「等这 22 道题过完之后，我希望你还能给我出一个前沿的题库表单，来方便我继续补充知识面……我希望我这里最后可以形成一套学习的体系出来。」
> **本目录就是二期的建设地**——现在的候选议题与漂移观察都是它的种子。

**产出物**：`前沿题库.md`（一份结构化题单），每题一行：`Txx 编号｜题面｜模块归属｜来源｜优先级｜题眼（提示层）`。

**建设方法**（届时按此执行）：

1. **捞新面经**：搜 2026 下半年 Agent 方向面经，与 Q01–Q22 对表，缺口成题
2. **翻台账**：[基线核查台账](../00-索引/基线核查台账.md) 的常设观察项与「题目集合漂移」六方向，逐条问「这里如果出一道题，题眼是什么」
3. **收种子**：本页候选议题表全部转正或淘汰，各题追问链里反复出现的方向升格成题
4. **联网核查**：每道新题的题眼必须有 2026 年的一手来源撑着，不出「已经过时的前沿题」

**出题纪律**（对维护方自己生效）：只写题面和题眼，**不写答案**——答案的价值在于用户自己推出来，这条与一期完全一致。题眼相当于出题人的提示，深度以「指出该往哪层挖」为限。
