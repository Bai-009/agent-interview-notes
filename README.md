## 〇、三条规矩（对话协议）

**一、每题四步走**：裸答（60 秒版本）→ 及格线（题库标准答案核心）→ **生产级那一层**（拉到超过题库）→ **一句杀手句**收尾（面试里能直接说出口的那种）。

**二、把题库当靶子，不当圣经。** 标准答案是八股水位——够过筛，但好几道停在"背得出"。目标是**每一题都答出题库没有的那一层**。

**三、节奏是每次两三题，对话式，不赶进度。**

> 记录文件的第 4 节对应"及格线+生产级"，第 9 节固定是**杀手句**。

## 一、怎么用（工作流）

**你做的**：把过程原样贴给我就行——面试官的问题、你当时的回答、后续的讨论/查资料的过程，乱一点没关系。

**我做的**：
1. 判断这题属于哪个主题目录，分配全局编号 `Qxxx`
2. 按 [`_模板/题目模板.md`](_模板/题目模板.md) 生成记录文件
3. **原样保留你的原始回答**（不美化——这是复盘的基准线）
4. 做差距诊断、补完整答案、挖第一性原理、准备追问链
5. 更新 [复习清单](00-索引/复习清单.md) 和本文件的索引
6. 原始粘贴内容存档到 [`_原始记录/`](_原始记录/)

**触发方式**：直接贴 + 一句「记一下」即可。想微调可以说：
- 「这题只要速览，不用展开」
- 「难度调到 ★★★★★」
- 「归到 05-工具调用与MCP」
