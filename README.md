## 答题方法：四步走

| 步骤 | 做什么 |
| --- | --- |
| ① **原始回答** | 60 秒版本，不查资料，先说出当下的真实理解 |
| ② **及格线** | 题库标准答案的核心——足以通过初筛的那一层 |
| ③ **生产级** | 用推导过的原理把答案拉到**超过题库**的那一层 |
| ④ **核心结论** | 一句可以在面试中直接表述的收尾判断 |

三条规矩：

1. 每题四步走
2. **把题库当基准，不当上限** —— 标准答案是模板化答案的深度，好几道停在「背得出」。目标是每题都答出题库没有的那一层
3. 每次两三题，对话式，**不赶进度**

## 每篇记录的结构

| 区块 | 作用 |
| --- | --- |
| **⚡ 30 秒速览** | 复习时**只看这块**：一句话答案 · 必覆盖关键词 · 上次的失分点 · 答题骨架 |
| **我的原始回答** | 一字不改，不美化 —— 这是复盘的基准线 |
| **差距诊断** | 四维评估（准确性 / 深度 / 结构 / 落地感）+ 指出「最致命的一条」 |
| **完整答案** | 一句话定义 → 分层展开 → **代价与边界** → 加分项 |
| **第一性原理** | 再挖一层：本质约束是什么、不这么做会怎样 |
| **追问链** | 面试官往下问什么，带自查勾选框 |
| **待查清单** | 自己挂起的问题 —— 「我不知道但我知道该查什么」是加分项，不是污点 |
| **查证记录** | 每一处硬引用的核实结果、本次新增、用词校准、存疑不背书的部分 |
| **核心结论** | 面试中可以直接表述的一句话判断 |

## 掌握度与复习节奏

🟢 已掌握（能主动展开 + 应对追问）｜🟡 待巩固（能答但不完整）｜🔴 未过关｜⬜ 未作答

复习采用**统一复习制**：做题期间不排日历，每题的失分点持续积累进[复习清单](00-索引/复习清单.md)的弱点档案；全部题目完成后按三轮规律复习——**清弱点 → 串主线 → 模拟追问**。做题过程中的自然复习（新题复用旧题结论）是主要的间隔重复来源。

### 怎么复习：不读，被问

> **看得懂 ≠ 说得出，所以复习不看文件。** 本仓库带一个 Claude Code 技能 [`.claude/skills/review/SKILL.md`](.claude/skills/review/SKILL.md)：
>
> ```text
> /review Q11          ← 复习某一题
> /review              ← 留空：列出 🔴 / 🟡 的题让你挑
> /review 主线名        ← 学完后第二轮：从头讲一条主线
> ```
>
> 直接说「复习 Q11」「问我」「验收」也能触发；记不住就敲斜杠命令，那个是硬的。
>
> 它做的事：按该题的速览和追问链**一次一问、不给提示**；答对了说具体对在哪，答错了**先拦再拆成更小的问题**，最多三步才给答案；结束贴记分表、判掌握度、把你的原话归档、更新记录和复习清单。**你全程不打开任何文件。**
>
> 立这条的原因（2026-09-06）：第一次跑通时，拦下的两处正是记录里预判「讲过、但没说出口」的两块——**讲过的留不住，说过的才留得住。**
