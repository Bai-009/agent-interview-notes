# AI Agent 面试题库 · 攻题记录

**这不是一份答案集，是一份攻题过程的复盘记录。**

标准答案到处都有，真实的思考落差没有。所以这里每一题都保留三样东西：**我当时的裸答（一字不改）**、**差在哪的逐条诊断**、**能扛住追问的生产级答案**。

`进度 3 / 22` `进行中 1` `更新 2026-08-28`

## 攻题方法：四步走

| 步骤 | 做什么 |
| --- | --- |
| ① **裸答** | 60 秒版本，不查资料，说个大概 |
| ② **及格线** | 题库标准答案的核心——够过筛的水位 |
| ③ **生产级** | 用推导过的原理把答案拉到**超过题库**的那一层 |
| ④ **杀手句** | 一句面试里能直接说出口的收尾 |

三条规矩：

1. 每题四步走
2. **把题库当靶子，不当圣经** —— 标准答案是八股水位，好几道停在「背得出」。目标是每题都答出题库没有的那一层
3. 每次两三题，对话式，**不赶进度**

## 每篇记录长什么样

| 区块 | 作用 |
| --- | --- |
| **⚡ 30 秒速览** | 复习时**只看这块**：一句话答案 · 必说关键词 · 上次踩的坑 · 答题骨架 |
| **我的原始回答** | 一字不改，不美化 —— 这是复盘的基准线 |
| **差距诊断** | 四维打分（准确性 / 深度 / 结构 / 落地感）+ 揪出「最致命的一条」 |
| **完整答案** | 一句话定义 → 分层展开 → **代价与边界** → 加分项 |
| **第一性原理** | 再挖一层：本质约束是什么、不这么做会怎样 |
| **追问链** | 面试官往下问什么，带自查勾选框 |
| **待查清单** | 自己挂起的问题 —— 「我不知道但我知道该查什么」是加分项，不是污点 |
| **杀手句** | 面试里能直接说出口的一句 |

## 掌握度与复习节奏

🟢 已掌握（能主动展开 + 扛住追问）｜🟡 待巩固（能答但不完整）｜🔴 未过关｜⬜ 未作答

间隔重复：**首答 → +1天 → +3天 → +7天 → +21天 → +60天**。🟢 跳一档，🔴 退回 +1 天。

> **复习方法**：只看「⚡30 秒速览」，**先合上文件口述一遍**，再对照检查。
> **看得懂 ≠ 说得出。**
