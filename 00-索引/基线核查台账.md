## 本轮（2026-08-28）核查出的落后模式

把四题的落后点放在一起看，**落后不是随机的，有三种固定形态**——以后核查时先按这三类找：

| 形态 | 长什么样 | 本轮的例子 |
| --- | --- | --- |
| **① 实现层翻代** | 原理没错，但举的实现是上一代 | Q05 停在 Outlines（2023），生产上跑的是 XGrammar |
| **② 被当成常量的变量** | 把一个其实在被工程手段推动的量，写成了固定约束 | Q03 把「经济窗口」当成给定的显存账，实际它被 GQA→MLA→稀疏注意力一路平移 |
| **③ 缺上位概念** | 局部判断都对，但没接到当年通行的大框上 | Q06 只在 FC / RAG 之间辨析，没提「上下文工程」这个 2026 年的总纲 |

> 第 ② 类最值得警惕：它不表现为「说错了」，而表现为**结论仍然成立、但那个结论已经不重要了**。

## 常设观察项（每次核查先看这几条有没有翻转）

- [ ] **长上下文**：有没有出现比 RULER / NoLiMa 更被接受的有效窗口基准？现有基准是否已饱和？
- [ ] **注意力架构**：KV cache 这条线是否又往下走了一代（MLA 之后是什么）？稀疏注意力对**有效窗口**是拉高还是压低？
- [ ] **约束解码**：主流推理框架的默认后端换了没有？「格式约束伤推理 10–15%」这条在带长思维链的推理模型上是否被重测？
- [ ] **幻觉**：主流准确率基准是否真的开始给「表达不确定」计分？（OpenAI 那篇提的社会技术改革有没有落地）
- [ ] **检索架构**：agentic 检索的成本是否已被压到可以当默认？「经典 RAG 仍是强默认」这条会不会翻转？
- [ ] **厂商声称**：本仓存疑表里的条目，有没有哪一条已经补上了可验证的基准成绩？
- [ ] **题目集合**：有没有新一批面经可以对表？Harness / 多代理 / 评测与成本这三个漂移方向，题库覆盖率如何？

## 核查纪律

1. **查证与基线核查分开写**，不要混进同一节——一个是对错，一个是新旧。
2. **落后点要写成"原文说了什么 → 现在是什么"**，不要直接把原文改掉。原文错在哪，本身就是复盘材料。
3. **一手来源才进正文**，二手行业博客一律进「存疑不背书」。本轮就挡掉了三条流传较广但查不到出处的数字。
4. **不核查未作答的题**，避免泄题。
