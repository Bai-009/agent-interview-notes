## 本轮（2026-08-28）核查出的落后模式

把四题的落后点放在一起看，**落后不是随机的，有三种固定形态**——以后核查时先按这三类找：

| 形态 | 长什么样 | 本轮的例子 |
| --- | --- | --- |
| **① 实现层翻代** | 原理没错，但举的实现是上一代 | Q05 停在 Outlines（2023），生产上跑的是 XGrammar |
| **② 被当成常量的变量** | 把一个其实在被工程手段推动的量，写成了固定约束 | Q03 把「经济窗口」当成给定的显存账，实际它被 GQA→MLA→稀疏注意力一路平移 |
| **③ 缺上位概念** | 局部判断都对，但没接到当年通行的大框上 | Q06 只在 FC / RAG 之间辨析，没提「上下文工程」这个 2026 年的总纲 |

> 第 ② 类最值得警惕：它不表现为「说错了」，而表现为**结论仍然成立、但那个结论已经不重要了**。

### 2026-08-29 补充：形态①的一个更短的时间尺度

Q09 出现了一个前几轮没见过的情况——**落后发生在「刚刚查证过」的内容上**。

出题人在本轮当场做了检索，查到「Codex 的 `max_depth` 默认为 1，所以孙子 Agent 不存在」，并据此更正了自己上一轮编造的例子。**查到的内容属实**，但它描述的是**多 Agent v1** 的行为——四个月前（2026-04-29）合并的一个改动已经把这道护栏从 v2 里整个移除了。

| | 以往假设 | Q09 的实际情况 |
| --- | --- | --- |
| 落后的时间尺度 | 一两年（Outlines→XGrammar、GQA→MLA） | **四个月** |
| 落后的来源 | 归档时写下的旧知识 | **本轮刚刚检索到的结果** |

**两条操作层的推论**：

1. **工具与框架类的事实，检索到就要问一句「这是哪个版本的行为」**——它们的迭代周期远短于论文。论文的结论可以放两年，一个配置项的语义可能三个月就换了。
2. **看到「有 issue 报告它不生效」时，先别当缺陷看**——那往往是**行为已经被主动改掉、文档还没跟上**的信号。Q09 里那份「设了 max_depth=1 仍生出孙子」的报告，正是那次移除的下游现象，不是偶发缺陷。

### 2026-08-30 补充：第四种落后形态——**范围外推**（引用没错，量词错了）

前三种落后形态（实现层翻代 / 被当成常量的变量 / 缺上位概念）说的都是「内容旧了」。Q09 暴露出第四种，性质不同：

> **一手来源写的是「我们的系统怎么做」，被写成了「行业上大家怎么做」。** 引用准确、日期也不算旧，但结论的适用范围被悄悄放大了一圈。

**本次实例**：依据 Anthropic 那篇多 Agent 工程博客（原文主语是「our lead agents」），[[Q09-主子Agent通信与异常]] 4.6 写成了「**同步仍是生产主流形态**」。反例是同一家公司的另一条产品线——Claude Code 的子 Agent 默认后台并发，主 Agent 在等待期间继续与人对话。**一个反例即推翻。**

| | 前三种形态 | 第四种（范围外推） |
| --- | --- | --- |
| 出问题的是 | 内容的**新旧** | 结论的**适用范围** |
| 怎么发现 | 检索更新的来源 | **找一个反例**——只要一个 |
| 怎么预防 | 定期核查 | 写「主流 / 通常 / 大多数」之前先问「我有没有跨系统的证据」；没有就把主语写回来源本身 |

**三条操作层的推论**：

1. **量词是承重的。** 「某系统是同步的」和「同步是主流」是两个论断，后者的举证责任大得多，而一手来源几乎从不为它举证——厂商只描述自家系统。**能不写量词就不写。**
2. **反例比新来源便宜。** 核查前三种形态要靠检索比对，核查这一种只要举出一个不符合的系统即可。**所以每写下一个「主流」，就顺手想一个反例；想不出来，说明证据不够而不是判断正确。**
3. ⭐ **最容易被忽略的一手来源，是手边每天在用的那个工具。** 这次推翻它的不是新检索，是**用户自己屏幕上的一张截图**。核查时习惯性去翻论文、文档、issue，却漏掉了正在使用的产品——而它恰恰是可以直接观察、无需转述的一手来源。**以后核查涉及某个工具的行为时，先看它在本机上到底怎么表现。**

## 核查纪律

1. **查证与基线核查分开写**，不要混进同一节——一个是对错，一个是新旧。
2. **落后点要写成"原文说了什么 → 现在是什么"**，不要直接把原文改掉。原文错在哪，本身就是复盘材料。
3. **一手来源才进正文**，二手行业博客一律进「存疑不背书」。本轮就挡掉了三条流传较广但查不到出处的数字。
4. **不核查未作答的题**，避免泄题。
