| **Chain of Thought Empowers Transformers to Solve Inherently Serial Problems** | Zhiyuan Li, Hong Liu, Denny Zhou, Tengyu Ma · [arXiv:2402.12875](https://arxiv.org/abs/2402.12875) · **ICLR 2024** | [[Q02]] **「CoT = 用 token 买串行计算深度」的形式化背书**。无 CoT 时常数深度、常数位精度 transformer 表达力上界卡在 **AC⁰**（AC⁰ ⊊ TC⁰）；**T 步 CoT** 后可解任何**规模为 T 的布尔电路**能解的问题。实验：置换群复合、迭代平方、电路值问题，**层数越浅受益越大** |

| **When Attention Sink Emerges in Language Models: An Empirical View** | [arXiv:2410.10781](https://arxiv.org/abs/2410.10781) · **ICLR 2025** | [[Q02]][[Q03]] attention sink 的**成因**：首 token 充当**偏置**，其 key 与其他 token 的 query 夹角普遍很小；sink 在充分数据上优化后**自然涌现**。细节：首 token 隐状态 ℓ2 范数显著更大，但 K/V 的 ℓ2 范数显著更小 |
| **Reasoning Models Don't Always Say What They Think** | Anthropic Alignment Science · [arXiv:2505.05410](https://arxiv.org/abs/2505.05410)（2025-05） | [[Q02]] **CoT 不保真**。方法：在 prompt 里埋"提示"，对比有无提示两组回答——模型用了提示却常常不在 CoT 里说出来。结论指向 CoT 监控在安全场景的可靠性上限 |
| **On the Biology of a Large Language Model** | Anthropic · transformer-circuits.pub（2025-03，对象 Claude 3.5 Haiku） | [[Q01]] **诚实边界**：训练目标是 next-token，不等于内部计算只想下一个 token。归因图显示模型写押韵诗时**提前选定行尾韵脚词**再倒推整行 |
| **DeepSeek-R1 incentivizes reasoning in LLMs through reinforcement learning** | DeepSeek-AI · **Nature 2025**（s41586-025-09422-z） | [[Q02]] **RLVR** 的代表工作；官方使用建议明确 **few-shot 会稳定拉低 R1 表现，推荐 zero-shot** |

## 引用纪律

1. **报得准**：标题、作者、年份、出处，缺一项宁可不报
2. **报得动**：能说清这篇支撑你哪个论点，不能只报名字
3. **分清声称与证据**：厂商声称单独归类，永远问一句「它拿什么基准撑的」
4. **未核实的一律标注**，宁可说"我记得有一篇但没核实过"
