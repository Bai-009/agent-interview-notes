## 六条主线（复习第二轮的六段叙述）

| 主线 | 一句话 | 已串起的题 | 将来会接的题 |
| --- | --- | --- | --- |
| **① 分布（尖锐/平坦）** | 全仓地基词汇：prompt 在选分布区，幻觉源于平坦，CoT 把一次平坦采样拆成一串尖锐采样，交叉熵是「学分布」的数学形式 | Q01 → Q02 → Q04 → Q05，Q07（回填数学形式） | Q13、Q19 |
| **② 信息住在哪 / 被压去哪** | 窗口装不下（Q03）、嵌入压掉稀有符号（Q07）、模型每轮失忆靠重拼（Q08）、子 Agent 回报是不可逆的有损压缩（Q09）、工具定义先占满窗口再谈干活（Q11）、早期约束的票数被近期 token 稀释（Q10）——同一个问题的五个现场：**信息不会自己留在该在的地方** | Q03、Q07、Q08、Q09、Q11 | Q10、Q15 |
| **③ 决定权：代码还是模型** | 贯穿全仓的主轴：白名单放行（Q05）、检索决定权（Q06）、请求权/执行权（Q08）、取消走独立通道（Q09）、沙箱划在内核而不是 agent 逻辑里（Q11）、hook 治「在但没照做」（Q10）——凡必须被遵守的，放代码层 | Q05、Q06、Q08、Q09、Q11 | Q14、Q17、Q20 |
| **④ 验证器：不信自报** | 模型的自我声明（答案、confidence、「我完成了」）一律不作数，求的是错误可检测；到 Q09 放大成「子 Agent 报完成同样不作数」，且「跑偏」是唯一只能靠验证器发现的失败形态；Q10 补上校验器的边界（抓离谱不抓合理但错）与多次采样测稳定性 | Q04 → Q05 → Q08 → Q09 | Q17、Q19、Q20 |
| **⑤ 分层经济学** | 便宜的扫全量、昂贵的处理短名单，且分层是被逼的：约束前移（Q05）、宽搜窄读（Q06）、召回+精排（Q07） | Q05、Q06、Q07 | Q14、Q16 |
| **⑥ 状态外置** | 状态住在模型外面、每轮重读：CoT 是最小版（Q02）、todo/文件是工程版（Q08）、跨进程版是「事件必须先被写成文字才存在」（Q09）、文件外置治「不在了」但治不了「在但没照做」（Q10） | Q02 → Q08 → Q09 | Q15、Q17、Q18 |

> 六条主线不平行——③④⑥在 Q08 汇成一句：**自主性 = 贪心的一步 × 会把结果拼回去的循环 × 外部验证。** 模块三往后，预计多数新题是这三条主线的组合题。
>
> ✅ **Q09 验证了这个预测**（2026-08-29）：它同时踩在 ②（回报是有损压缩）、③（取消走代码层）、④（子 Agent 报完成不作数）、⑥（事件必须先被写成文字）四条上，没有引入任何新的地基概念。**这也是复习第二轮该串的形状——模块三的题不该按题号背，该按主线串。**
