## 上线前必须定的三件事

### ☐ 1. 原始回答要不要公开？

**推荐：保留。** 这是全仓最稀缺的东西。

市面上 AI 面试题库仓库全是「问题 + 标准答案」，同质化到没有阅读价值。这个仓库的差异化就在于**保留了真实的思考落差**——「我当时答成这样 → 差在哪 → 生产级答案长这样」。抹掉原始回答，它就退化成又一个答案集。

如果介意暴露知识盲区：那正是读者会共情的部分，而且每一题都有配套的完整答案兜底，呈现的是「攻克的过程」而不是「不会」。

### ☐ 2. 选许可证

| 选项 | 适用 |
| --- | --- |
| **CC BY-NC-SA 4.0**（推荐） | 允许署名转载、禁止商用、衍生同协议。中文面经仓库常被打包进付费社群卖，这一条可以限制这种行为 |
| CC BY 4.0 | 只要求署名，随便用 |
| MIT | 面向代码的许可证，用在纯文档仓库上语义不太对 |

### ☐ 3. 仓库名与定位句

- 候选名：`agent-interview-notes` / `llm-agent-interview` / `agent-mianshi`
- 定位句（README 第一句）：要一眼说清「这不是答案集，是复盘记录」
